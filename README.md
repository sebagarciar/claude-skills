# Claude Skills

A few [Claude Code](https://claude.com/claude-code) skills I use day to day, shared as-is.

- **[tailor-cv](./tailor-cv)**: matches my CV to a job ad and outputs a one-page, ATS-optimized PDF.
- **[interview-prep](./interview-prep)**: researches a company, builds the stage-by-stage interview brief, then runs the mock.
- **[apply](./apply)**: job ad in: go/no-go against my CV bank, tailored CV, form answers, tracker row. Stops before Submit.
- **[find-jobs](./find-jobs)**: daily scan of new postings, ranked against my CV, as a one-page HTML report. Runs by hand.
- **[business-case](./business-case)**: case brief in, one deck and one numbers model out, with a review checklist.
- **[weekly-vault-review](./weekly-vault-review)**: weekly maintenance pass over my notes vault in Obsidian.
- **[wrap-up](./wrap-up)**: reviews a session for lessons worth keeping and proposes them to me one by one before writing anything down. `/wrap-up prune` reviews the rules already written and proposes what to keep, update, merge or delete.

The whole system these skills run in: [ia-os-template](https://github.com/sebagarciar/ia-os-template).

More at [sebasgarcia.dev](https://sebasgarcia.dev).
